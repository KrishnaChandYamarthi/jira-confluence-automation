# Weekly Status Report Instructions

- Follow `./instructions/write-reliable-output.agent.md`.
- Generate a weekly status report in Markdown.
- Include these sections, in this order:
  - Accomplishments
  - Blockers
  - Next Week
- Use bullet points only for report content; do not write paragraphs.
- Keep the entire report to a maximum of 20 lines, including headings.
- Use a professional, direct tone.
- Avoid fluff words and filler.
- If a section has no updates, include a concise bullet stating that there are none.
